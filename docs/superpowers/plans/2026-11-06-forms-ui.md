# 양식 자료실 화면 구현 계획

> 실행 방식: 현재 대화에서 직접 구현. 사용자가 승인한 #7 범위를 따르며 기존 API를 재사용한다.

**Goal:** 직원이 양식 게시글을 검색·조회·다운로드하고 관리자·담당자가 등록·수정·삭제한다.

**Architecture:** 기존 Ant Design 화면과 React Query, 인증 컨텍스트를 사용한다. 사용자가 하위 폴더까지 지원하는 공유 자료실로 범위를 변경했다. 폴더 탐색·경로 표시와 양식 상세를 연결하고, 양식은 기존 제목·설명·다중 첨부 모델을 유지한다. 기존 자료는 최상위 폴더에 보존한다.

**Tech Stack:** React, TypeScript, Ant Design, TanStack Query, 기존 Playwright Core.

**Spec:** [#7](https://github.com/ync-capstone-desgin/hkagri-supplier/issues/7), [자료실 API](../../forms-api.md), 사용자와 합의한 관리자·담당자 편집 / 조회자 다운로드 권한.

## 제약

- V9에서 폴더와 양식의 소속 폴더를 추가한다. 기존 V1~V8은 수정하지 않는다. 기존 파일 저장 API·권한과 의존성을 유지한다.
- 폴더 생성·이름 변경·빈 폴더 삭제를 지원한다. 하위 폴더·양식이 있으면 삭제를 거절한다. 폴더 이동·휴지통·외부 공유는 제외한다.
- 같은 부모 아래 동일 폴더명은 대소문자와 앞뒤 공백을 정리해 거절한다. 기본 최상위 폴더는 이름 변경·삭제할 수 없다.
- 기업 실자료는 코드·테스트·캡처에 넣지 않는다.
- 제목 200자, 설명 5000자, 분류 CONTRACT/CHECKLIST/OTHER.
- 기본 파일당 20MB, 새 파일 합계는 20MB까지 안내해 21MB multipart 요청에 헤더 여유를 둔다.
- 기존 UI 스타일과 한국어 문구·함수 주석을 유지한다.

## 검증할 경계

- 검색·분류 변경 시 첫 페이지로 돌아가고, 상세의 다중 첨부를 각각 내려받는다.
- 수정 취소는 파일을 삭제하지 않으며 저장 실패 시 입력과 파일 선택이 유지된다.
- 기존 파일 삭제와 새 파일 추가를 한 요청으로 처리하고 서버의 원자성을 유지한다.
- 조회자에게 편집 제어가 없으며 파일 초과·잘못된 형식은 저장 전에 안내한다.
- 목록·상세·다운로드 실패를 안내하고 다시 조회할 수 있다.
